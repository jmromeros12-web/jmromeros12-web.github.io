Git es un sistema de control de versiones distribuido que permite gestionar y rastrear los cambios realizados en proyectos de software. Fue diseñado para ofrecer un rendimiento eficiente, seguridad y flexibilidad, y es ampliamente utilizado tanto en proyectos de código abierto como comerciales.

SEO

SEO son las siglas en inglés de "Optimización para Motores de Búsqueda" (\(SearchEngineOptimization\)) y se refiere al conjunto de técnicas para mejorar la visibilidad de un sitio web en los resultados orgánicos y gratuitos de buscadores como Google. El objetivo es aumentar el tráfico de calidad hacia una página, optimizando aspectos como el contenido, la estructura técnica, y la autoridad del sitio, para que aparezca en las primeras posiciones de los resultados de búsqueda. 

Open Graph

Open Graph es un protocolo de marcado web creado por Facebook que permite controlar cómo se muestran los enlaces web en las redes sociales. Se implementa mediante etiquetas HTML en el código de una página para especificar información como el título, la descripción, la imagen y el tipo de contenido.
